# Alpine Linux package maintenance

This repository documents my work as an individual Alpine Linux package
maintainer.

The packages are contributed to Alpine Linux's shared
[`aports`](https://github.com/alpinelinux/aports) repository, which is
owned and maintained by the Alpine Linux project. This repository is not a
fork or replacement for `aports`.

## Package list

The automatically generated package list is published through GitHub Pages:

**<https://fcolista.github.io/alpine-maintainer/>**

The page is rebuilt automatically by GitHub Actions from the current Alpine
`aports` repository.

It lists packages whose current `APKBUILD` metadata identifies me as the
maintainer. The list may change as package ownership and Alpine metadata
change.

## What I maintain

My Alpine packaging work includes:

- Updating APKBUILDs and package versions.
- Handling dependency and soname transitions.
- Fixing build and test failures.
- Applying security and portability fixes.
- Supporting multiple Alpine releases and architectures.
- Updating Python, Perl, C, and other ecosystem packages.
- Coordinating changes with Alpine contributors and upstream projects.

## Automatic generation

The site is generated by:

```text
scripts/generate.py
```

and deployed by:

```text
.github/workflows/update-pages.yml
```

The workflow:

1. Checks out this repository.
2. Checks out the Alpine `aports` repository.
3. Scans package `APKBUILD` files.
4. Selects packages matching my maintainer identity.
5. Generates `site/index.html`.
6. Generates `site/packages.json`.
7. Publishes the result through GitHub Pages.

The workflow runs automatically on a schedule and can also be started
manually from the **Actions** tab.

## Local usage

Clone this repository and the Alpine `aports` repository:

```sh
git clone https://github.com/fcolista/alpine-maintainer.git
git clone --depth 1 https://github.com/alpinelinux/aports.git
```

Run the generator:

```sh
python3 scripts/generate.py ./aports ./site
```

Open the generated page:

```sh
xdg-open site/index.html
```

or serve it locally:

```sh
python3 -m http.server --directory site
```

Then visit:

```text
http://127.0.0.1:8000/
```

## Maintainer identity

The generator matches the maintainer identity configured in
`scripts/generate.py`. Update that configuration if the name or email used in
Alpine APKBUILD metadata changes.

The generated page intentionally distinguishes current maintainer metadata from
historical Git contributions. A package that I modified in the past is not
automatically presented as a package I currently maintain.
